## 6. אופציה ג' עכשיו · אופציה ב' מאוחר יותר

### אופציה ג' — מה לעשות עכשיו (זול, סוגר את הספרינט)
239 כבר נתן את חצי הווידאו. להשלים:
1. **מישור השאלות לצופה** — ViewerScreen מצטרף לחדר `gameId` (עם ה-`gameId` שחוזר מ-`STREAM.JOIN`) ומאזין ל-`GAME.NEW_QUESTION`. שינוי לקוח קטן.
2. **PlayerScreen** — CONSUME/RESUME → media socket. כבר בסקופ **SCRUM-224**.
3. **Reconnect rejoin** — SCRUM-286 (חסר בעלים — **להקצות**).
4. **M4-05** — RTP/SSRC אמיתי (חובה לשני משדרים במקביל).
5. **M4-10 + M4-11** — TURN/STUN + `enableTcp` (חובה לניסוי מחוץ למשרד/נטפרי).

### אופציה ב' — מה יידרש מאוחר יותר (ל-D-02 ולעמידות)
"ב'" אינו רק Redis adapter — שני שרתי ה-io הם תהליכים נפרדים עם חיבורי-לקוח נפרדים. ב' האמיתי = **ערוץ server→server (Redis pub/sub בין ה-backends)** שמאפשר ל-app-server להורות ל-media-server לפלוט אירוע.
- **זה בדיוק מה שנדרש ל-D-02 (השתקה server→media).**
- לכן: להוסיף את ה-bus **כשלב נפרד מאוחר יותר**, לא לגלגל אחורה את 239. כך מקבלים את יתרונות ב' (D-02, פחות שבריריות reconnect) בהדרגה, בלי לזרוק עבודה מוזגת.
- **גלגול אחורה מלא ל-ב' עכשיו = יקר ולא מוצדק.**
